## 区块顺序

1. Hero
2. Product video/mockup (center)
3. Feature breakdown per section
4. Comparison (optional)
5. CTA

## 设计决策

- **CTA 位置**：Video center + CTA right/bottom
- **配色策略**：Video surround: Brand color overlay. Features: Icon color #0080FF. Text: Dark #222
- **推荐效果与动效**：Video play button pulse, feature scroll reveals, demo interaction highlights
- **转化优化要点**：Use an interactive demo only when it explains value better than static media. Provide captions, transcript, visible play/pause controls, and a non-video fallback; do not autoplay under reduced motion. Pause media when offscreen or hidden and keep the final product state available as static content.
