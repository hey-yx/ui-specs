# USWDS · Measure 行长

> 来源：[https://designsystem.digital.gov/design-tokens/typesetting/measure/](https://designsystem.digital.gov/design-tokens/typesetting/measure/)

Design tokens

USWDS has 6 measure tokens to control the reading length of lines in a block of text.

## Measure tokens

Measure is output in `ex` units, where `1ex` is equivalent to the height of an 'x' character in the desired font. The first section of each example below is 4 alphabets long.

## Using measure tokens

Your context and coding style determine how you access USWDS measure tokens in code.

| Context | Usage | Example |
| --- | --- | --- |
| function | measure([measure](https://designsystem.digital.gov/design-tokens/typesetting/measure/)) | max-width: measure(`3`) |
| mixin | u-measure([measure](https://designsystem.digital.gov/design-tokens/typesetting/measure/)) | @include u-measure(`'none'`) |
| setting | [measure](https://designsystem.digital.gov/design-tokens/typesetting/measure/) | $theme-text-measure: `5` |
| utility | .measure-[measure](https://designsystem.digital.gov/design-tokens/typesetting/measure/) | .measure-`3` |
