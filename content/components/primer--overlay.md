# GitHub Primer · Component · Overlay

> 来源：https://primer.style/components/overlay

## Usage

  ⚠️ Usage Warning ⚠️
  Overlay is an internal component and is intended to be used as a private API, composing other components. It is not intended to be used on its own. For a ready-to-use overlay-type component, consider Dialog, Select Panel,  or Action Menu.

The overlay component handles all behaviors needed by overlay UIs as well as the common styles that all overlays should have. Overlay is the internal, or base component for many of our overlay-type components. Overlays use shadows to express elevation.
