# GitHub Primer · Component · Branch name

> 来源：https://primer.style/components/branch-name

![An image showing a branch name component.](https://user-images.githubusercontent.com/586552/207118150-306e0679-f77b-4668-8700-3da506256ad1.png)

## Usage

Use this component to represent a branch name label and link to its tree.

## Options

### Icon

Include the branch icon when using the component in isolation and in places where users can’t easily determine whether the label represents a branch from the surrounding context.

![An image showing a branch name component with a branch icon.](https://user-images.githubusercontent.com/586552/207118155-5660c7c8-32f0-4eee-84c6-ce2b5c98b3ba.png)

## As a link

Branch name is rendered as a link by default. You can also represent the branch label in plain text.

![An image showing a branch name component as a link and a branch name component as plain text.](https://user-images.githubusercontent.com/586552/204637507-08c61b68-c474-4d64-9d64-91bf46fcff42.png)
