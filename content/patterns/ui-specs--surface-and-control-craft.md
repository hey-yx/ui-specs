# 表面分层与控件质感：边界语言、按钮三级与浏览器原生表面

> 来源：[本库原创](https://github.com/hey-yx/ui-specs)

---

同一个设计系统选型，AI 写出来常显得「粗糙或像模板」，原因往往不在主色，而在表面边界堆砌、控件描边同质化、符号凑图标，以及遗漏浏览器原生表面细节。这篇把跨选型的通用表面语法与控件质感规则收成落稿基线。具体数值（色阶、字号、圆角、控件高度）仍一律从本项目选中的主源文章取。

## 一、四层表面与边界二选一

1. **按层级落表面 Token**：把界面表面按职责拆成四层——`canvas`（页底画布）、`sheet`（主内容承载体）、`raised`（浮层、抽屉、弹出菜单）、`inverse`（深色顶栏、Toast、工具提示）。明暗两套模式各自成套推导，不用纯黑 `#000000` 或纯白 `#ffffff` 糊死所有背景，而是贴合选中选型的中性灰阶与色调倾向。
2. **边界二选一，禁止「框套框」**：
   - 同一个容器要么用**底色明度差**分层，要么用 **1px 边框**分层，要么用**偏移软阴影**表达浮起；禁止在 1px 边框外再叠一层宽软阴影（幽灵卡片），也禁止在卡片里面反复套圆角灰框。
   - **禁止同类小卡片堆墙**：除非本身就是浏览目录或 Bento 展示，否则不要把 3 列以上相同规格的「图标 + 标题 + 简介」卡片铺成主内容区。
3. **列表与结构线克制**：相邻数据组优先用间距或单一 1px 发丝分割线拉开，避免每个子项都包进独立方框。

## 二、控件视觉层级与描边纪律

1. **禁止全员统一深灰实线边框**：如果主按钮、次按钮、输入框、开关、容器全部套着同样的深灰实线边框，界面会失去主次重心，视觉噪点急剧升高。
2. **按钮必须区分三级层级**：
   - **Primary（主操作）**：整视图唯一或极少数核心推进动作，实色填充（对比度达标），不靠粗外框抢眼；
   - **Secondary（次操作）**：浅底填充或弱边界，承载常见但不唯一的操作；
   - **Ghost / Text（辅助操作）**：无底色或仅悬停显底，用于关闭、取消、次要工具入口。
   - 危险/破坏性操作明确区分语义（如确认步骤或语义色），不与主推进操作抢同一实心主色。
3. **非文本边界与触控密度**：
   - 输入框、复选框、开关等需要用户辨识可输入/可点击范围的边界，其与相邻背景的非文本对比度不低于 `3:1`；装饰性分隔线不承担控件边界职责。
   - 桌面端控件紧贴选中选型的原生密度（通常 `32px–36px`，任意独立可点目标不低于 `24px`）；移动端（`< 768px` 或 `pointer: coarse`）通过媒体查询扩展至 `>= 44px`。
   - 悬停态样式包裹在 `@media (hover: hover)` 内，防止触屏点击后悬停态粘滞。

## 三、图标系统一致性与字符禁令

- **禁止用字符或 Emoji 凑图标**：严禁在操作按钮、状态角标、空态插槽里用 `▶`、`■`、`⚙`、`🔍` 或 Emoji 充当 UI 图标；Emoji 只允许出现在真实的表情输入或明确的用户头像/内容文本中。
- **单一线宽的矢量图标**：操作按钮与空态使用统一的 16px/20px 内联 SVG 线性图标（同一页面保持统一的 `stroke-width`、`stroke-linecap` 与视觉体量），或完全使用选型配套的官方图标库，不混搭两套以上图标风格。
- **可达性配对**：纯图标按钮必须提供可读的 `aria-label`（必要时配 tooltip）；紧邻文字标签的装饰性图标标注 `aria-hidden="true"`，防止读屏重复播报。

## 四、浏览器原生表面与排版微细节

模型最容易忽略、但最能把「拼装页面」变成「工程成品」的细节，是把浏览器默认表面一起纳入设计系统 token：

- **文本选区与光标**：为 `::selection`（与主色或次级底色协调的透明高亮）和输入框 `caret-color` 绑定语义 token。
- **焦点环（Focus Ring）**：定制高对比 `:focus-visible` 轮廓（如 `2px` 实线加 `2px` 偏移），与相邻背景保持 `>= 3:1` 对比度，且 **不加 `transition`**，保证键盘按 Tab 时焦点瞬间清晰落位。
- **数据等宽对齐**：所有价格、版本号、时间戳、耗时、百分比、指标数字与表格数值列默认开启 `font-variant-numeric: tabular-nums`，避免数值刷新时列宽跳动；中文混排、超长 ID 与 URL 显式处理折行（`overflow-wrap: anywhere`）或单行截断，防止窄屏撑破布局。
- **自定义滚动条与下划线**：长列表或代码/日志面板的滚动条色调与表面融合；文本链接设定克制的 `text-underline-offset` 与细线宽，避免默认粗线压住下行字脚。
