## 4. 数值文章缺口与已知限制

- Apple HIG 原文色值表采用 iOS 语义分层名且配 PNG 样本，hex 色彩、间距与动效时长按 `GAP_RULES` 分别回源 TDesign、优设 8px 与 NN/g。
- 本地演示不接真实大模型 API 与短信通道。
