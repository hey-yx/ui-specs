## 3. 键盘与焦点

- Tab 顺序实测：Skip to content → 品牌 → 搜索 → Docs → API → Changelog → Get API key。每一站都有 2px 可见轮廓，焦点没有丢。
- 搜索弹层：⌘K / Ctrl K 打开，焦点进入输入框；Shift+Tab 从输入框回绕到最后一个结果，Tab 从最后结果回绕到输入框；Esc 关闭并回到搜索按钮。
- 搜索选择：Enter 打开结果后焦点落到目标标题，避免弹层关闭后焦点留在 body。
- Tabs：左右方向键、Home / End 都能切换，`aria-selected` 与面板 `hidden` 同步。
- 试解析：输入为空时错误文本通过 `role="alert"` 出现，焦点回到输入框；提交中按钮禁用，成功后恢复。
- 复制：测试环境剪贴板权限被浏览器拒绝，页面给出「Select the code and press ⌘C」的可见反馈，没有静默失败。真实浏览器有剪贴板权限时会写剪贴板。

## 5. 动效

- 100ms 用于按钮、链接、Tabs 的颜色与边框反馈；200ms 用于弹层退场；300ms 用于弹层进场。
- `prefers-reduced-motion: reduce` 下实测 `transition-duration: 1e-05s`（0.01ms），弹层与 Toast 都不再位移。
- 弹层关闭先加 `is-closing`，等过渡结束再 `hidden`，不是直接 display:none。

## 7. 设计点盲测

| 题 | 答 | 本案落地 |
| --- | --- | --- |
| 优设的间距规范以什么为基数，衍生哪几个数，为什么不用 40 和 56？ | 8px 基数，衍生 8 / 16 / 24 / 32 / 48 / 64；40 与 56 在大数值段与相邻档的倍数差太小（56 对 64 只有 1.14 倍），视觉上分不出层级（`content/layout/uisdc.com--code-for-design-of-spacing.md:102`）。 | 全站只用 8 / 16 / 24 / 32 / 48 / 64；组件内距另标 derived。 |
| NN/g 说进入和退出屏幕的时长有什么差别，弹窗例子是多少？ | 进入要比退出稍长；弹窗约 300ms 进入，200 或 250ms 退出（`content/motion/nngroup.com--animation-duration.md:84`）。 | 搜索弹层 300ms 进、200ms 出。 |
| W3C 的 ease-out 等价于哪条曲线？ | `cubic-bezier(0, 0, 0.58, 1)`（`content/standards/w3c--css-easing-1.md:138`）。 | `--ease-out` 直接用这条。 |
| Practical Typography 给多数文本的最优行距区间是多少？ | 字号的 120% 到 145%；文中 110% 的示例被判为过紧（`content/type/practicaltypography.com--line-spacing.md:26`）。 | TDesign 的 +8 行高在 14px 为 157%、16px 为 150%、36px 为 122%，高于 145% 的两档是缺口回源 TDesign 的结果；这是本案的取舍，不声称满足 120% 到 145% 全区间。 |
| 等待过程按等待时长怎么分档？ | 不到 1 秒不显示加载态；1 到 3 秒用不定量加载态；3 秒以上用定量进度；超过 10 秒转后台任务（`content/patterns/ui-specs--test-walkthrough.md:35`）。 | 试解析 1.2 秒，用骨架屏，属 1 到 3 秒的不定量档。 |
| 底线复测看哪些数值？ | 正文 4.5:1，大字与非文本 3:1，焦点态与非焦点态 3:1，指针目标不小于 24 × 24 CSS 像素（`content/patterns/ui-specs--test-walkthrough.md:47`、`content/a11y/w3c--wcag-2.2.md:907`）。 | 逐项实测见第 2 节与第 3 节。 |

TDesign 的 768 / 992 / 1200 断点 checks 不适用于本案：基准是 Primer，页面用 Primer 的 768 / 1012 / 1280，TDesign 断点只作对照，不落到页面。

## 8. 未验到与已知问题

1. **命名判负**：`payloaddeck.com` 是上线产品，标题 `Connected tools. Focused work. · PayloadDeck`。本案例由 brief 固定用这个需求名，页面里的 API 与 SDK 都是演示数据，发布前必须改名。按 NameYouLike 口径核验过的备选 `LogShape`：npm/PyPI 404，`logshape.com` / `.io` / `.dev` / `.app` 全部可注册，GitHub 只有 2018 年的 0 star 脚本与一个无描述新仓；可作为改名首选。两名的商标都未查。
2. **字体依赖系统**：Primer 只给 system fonts 原则，页面不加载外部字体；不同系统的实际字形会略有差异。
3. **剪贴板**：测试环境拒绝剪贴板写入，只验证了失败提示；成功写入需要在有权限的真实浏览器补测。
4. **未测浏览器**：只在 Chromium 测过，Safari 与 Firefox 未跑。
5. **无真实 API**：试解析是本地固定数据，不发送请求；页面不承诺真实延迟。
6. **窄屏内部滚动**：代码块与 4 列参数表在 375 档需要容器内横向滚动，页面级无溢出。
