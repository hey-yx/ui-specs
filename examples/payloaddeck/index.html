    PayloadDeck API

    Send a raw log line, get structured fields back. This page takes you from an empty terminal to a working request, then gives you the field and error tables to check against.

    Base URL
    https://api.logreap.dev
    Parse endpoint
    POST /v2/parse
    Authentication
    Bearer token in the Authorization header
    Payload
    JSON, UTF-8, 256 KB maximum
    Rate limit
    600 requests / minute

    Quickstart

    Four steps, about two minutes. Everything below is a static example: this page never sends a request to the API.

    1. Create a service key in your PayloadDeck workspace.
    2. Pick a parser, or omit parser and let the API auto-detect the format.
    3. Send one log line to POST /v2/parse.
    4. Read the returned fields and check any error code against the table below.

    Send the request

    Copied 
    curl -X POST https://api.logreap.dev/v2/parse \
  -H "Authorization: Bearer $LOGREAP_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "line": "127.0.0.1 - [07/Nov:09:12:44] \"GET /v2/health\"",
    "parser": "nginx"
  }'
    const res = await fetch("https://api.logreap.dev/v2/parse", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${process.env.LOGREAP_KEY}`,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    line: '127.0.0.1 - [07/Nov:09:12:44] "GET /v2/health"',
    parser: "nginx"
  })
});
const data = await res.json();
    import os, requests

res = requests.post(
    "https://api.logreap.dev/v2/parse",
    headers={"Authorization": f"Bearer {os.environ['LOGREAP_KEY']}"},
    json={
        "line": '127.0.0.1 - [07/Nov:09:12:44] "GET /v2/health"',
        "parser": "nginx",
    },
)
data = res.json()

    Request fields

    All fields go in the JSON body. Only line is required.

    Body fields for POST /v2/parse
    FieldTypeRequiredDescription
    linestringyesRaw log line to parse.
    parserstringnoNamed parser: nginx, syslog, json. Omit to auto-detect.
    timestamp_formatstringnoOverride for the inferred timestamp layout.
    timezonestringnoIANA zone used when the line has no offset. Defaults to UTC.
    include_rawbooleannoEcho the original line in the response. Defaults to false.
    fieldsarraynoRestrict the returned field set.
    request_idstringnoYour correlation id, echoed back unchanged.
    strictbooleannoReject partially matched lines. Defaults to false.

    Response

    A successful parse returns the detected parser, a confidence score, and a flat field map.

    id
    Unique id for this parse result.
    parser
    The parser that matched, or the one you requested.
    confidence
    0.0–1.0
    fields
    Extracted key/value pairs; keys depend on the parser.
    request_id
    Your correlation id, if supplied.
    duration_ms
    Server-side parse time in milliseconds.

    Error codes

    Errors use the HTTP status plus a machine-readable code. Search the table as you read.

    Showing 9 of 9

    No codes match that search. Try a shorter term.

    Error codes returned by /v2/parse
    HTTPCodeKindMeaningWhat to do
    400invalid_jsonClient errorThe body is not valid JSON.Validate the body before sending.
    401missing_keyClient errorNo API key was supplied.Add the Authorization header.
    403key_revokedClient errorThe API key has been revoked.Issue a new service key.
    413payload_too_largeClient errorBody exceeds 256 KB.Split the batch.
    422unparseable_lineClient errorNo parser matched the log line.Set a parser explicitly.
    429rate_limitedClient errorToo many requests this minute.Back off and retry.
    500internal_errorServer errorUnexpected server error.Retry with the same request id.
    503parser_unavailableServer errorThe requested parser is offline.Omit parser to auto-detect.
    504upstream_timeoutServer errorThe parser timed out.Retry once, then report it.
