## 2. 数值缺口与替代

基准规范 TDesign 覆盖了色板、字阶、行高、字重、字体栈、间距尺度、断点、动效时长与缓动 —— 这 8 个维度**没有走回源**，直接用基准规范原值。真正缺的维度按下表处理：

| 缺口 | 处理 | 值 | 对应 GAP_RULES 条 |
| --- | --- | --- | --- |
| 圆角 | derived，整站两档 | 4px（控件）/ 8px（摘要卡） | 「圆角」 |
| 组件尺寸 | derived，成套自定 | 控件高 44px；行高由字高公式决定 | 「组件尺寸」 |
| 触控目标 | 按 WCAG 下限再取稳 | 44px | 「触控目标与焦点环」 |
| 焦点环 | derived | 2px 实线 + 2px 偏移 | 「触控目标与焦点环」 |
| 发丝线宽 | derived | 1px | 「发丝线宽」 |
| 正文行长 | derived，同页一种 | 45em（14px 下 ≈ 45 字） | 「正文行长」 |
| 图表几何 | derived 全站一套；构图原则回源 Carbon 图表解剖 | 绘图区 200px、2px 线、9px 实心点 / 11px 空心环、1px 网格、5 个横坐标点 | 「图表几何参数」 |
| 数字字体 | 降级，不冒充原值 | `font-variant-numeric: tabular-nums` 替 TCloud Number | 「数字字体」 |
| 色阶当文字 | 实算后同族换档 | Blue6 `#366ef4` 承白字 4.47:1 不达 AA → hover 换 Blue8 `#003cab`（9.40:1） | 「色阶当文字」 |
| 弹层遮罩 | derived，全站一档 | `rgba(0,0,0,.45)` | 「弹层遮罩」 |
| 浮层宽 | derived，随内容 | `min(100%, 520px)` | 「组件尺寸」（同条类推） |
| 提示框定位 | derived | 先量宽再夹在绘图区内 | 「图表几何参数」（同条类推） |
| 金额排版 | 不适用 | 本页无金额 | 「金额排版」 |
| 首屏占比 | 不适用 | 无 hero，首屏即内容 | 「首屏占比」 |
| 间距 | 基准规范有，未回源 | 4/8/12/16/24/32/48（`content/layout/tdesign.tencent.com--layout.md:65` `:107`） | 「间距」 |
| 动效 | 基准规范有，未回源 | 100/200/240ms + 三条 cubic-bezier（`content/motion/tdesign.tencent.com--motion.md:96` `:99` `:100` `:111-113`） | 「动效时长与缓动」 |
| 字阶 / 色值 / 字重 / 字体栈 | 基准规范有，未回源 | 14/20/36；16 个色 token；400/600；系统栈 | 「字阶」「色值」 |

**没有跨源拼数值**：Carbon 只提供构图原则（九要素、从零起、图例交互、悬停降透明到 30%），不提供任何 hex、字号、间距；NN/g 只用于核对动效量级与三档层级，不取时长数值。

## 3. 新缺口：指南没有、被迫派生的维度

以下 6 条是这稿真实卡住的地方，指南的 15 条 GAP_RULES 都没覆盖到，最后靠现场规则定死。建议回填。

1. **状态型浮层的开合要不要过渡**
   抽屉里同时跑进度条，开合动画会和进度推进抢帧，也让「开/合」状态与 `aria` 状态之间出现中间态，自验读数不稳。本稿改成即时切换。
   *建议回填*：补一条「浮层开合与可测性」——承载进度或结果的状态型浮层优先即时，装饰型浮层才用 240–280ms。

2. **图表提示框（tooltip）的定位与夹取**
   基准规范给时长给缓动，但不给浮层定位规则。窄屏悬停最右点时，按百分比定位会越界。
   *建议回填*：浮层「先量宽再夹取」的通用规则（`max(0, min(containerW − tipW, x))`），并明确提示框不参与页面溢出计算。

3. **图表标记的成套编码**
   「不要只靠颜色」是原则，但没给可执行的编码组合。本稿定的是：实际 = 实线 + 实心点，计划 = 虚线（5/4）+ 空心环（11px vs 9px），色相区分只作第三通道。
   *建议回填*：一条「图表标记编码」——两条以上系列时，线型与标记必须不同，且图例色块纹理要与线型一致（第一版就是这里出的错，见 DECISIONS §9）。

4. **筛选 0 条时的空态与计数联动**
   指南说空态要给下一步，但没说计数播报要不要跟着改、标题要不要改。本稿保持「共 0 条」由 `role="status"` 播报，空态文案给「点全部」与「切周期」两个出口。
   *建议回填*：空态时的播报口径（只播条数，还是条数 + 下一步）。

5. **浮层内表单校验的降级路径**
   GOV.UK 那套是整页表单：错误摘要放 `main` 顶部并抢焦点。抽屉里只有单字段，抢焦点会把用户从输入框踢走。
   *建议回填*：字段级校验在浮层内的降级规则（保留 `Error: ` 标题前缀与字段旁消息，不做页面级摘要，不抢焦点）。

6. **虚构数据声明的位置与强度**
   「要标明是虚构数据」没说到什么程度。本稿只在页脚放一行「演示数据，非真实团队记录」，首屏不额外标注。
   *建议回填*：声明放页脚即可，还是必须在首屏可见范围内出现一次。

另外两条较小的：抽屉宽与正文容器宽（520px 对 45em）不同量纲，靠「随内容定」蒙过去；`prefers-reduced-motion` 下是否连 `hidden` 切换也要保留（本稿保留，因为它不是动效）。

## 4. 已知局限

- **浏览器只测了 Chrome**（Chromium，macOS）。Safari 的滚动条占宽策略不同（`layout.md:121` 专门提过这事），四档 `scrollWidth` 结论未在 Safari 复验；Firefox 完全未测。
- **四档是设备模拟，不是真机**。320 / 375 / 768 / 1280 用 `Emulation.setDeviceMetricsOverride` 设定（DPR 1，320 档另以 DPR 2 复看截图）；iOS Safari 的地址栏收缩、`100vh` 行为未验证（本页没有用 `100vh`）。
- **剪贴板只验了成功分支**。真鼠标手势下 `navigator.clipboard` 写入成功，显示「已复制 239 字」；权限被拒时的失败文案（「复制失败，请手动选中摘要文本」）只有代码路径，未在真实拒绝环境触发过。
- **数据是写死的演示数据**。两个周期各 5 名成员、两套燃尽序列都是需求里的示例形态，不来自任何真实团队；页脚已声明。
- **只做浅色一套**。基准规范有暗色篇，本稿未落；色 token 是单值，没有做深浅两套映射。
- **未启用 12 栅格**。单栏文档不需要列划分，只保留了槽 16px 与安全边距 24px 两个基准规范值。
- **焦点陷阱只处理 Tab / Shift+Tab 循环**。抽屉内没有 iframe、Shadow DOM、`contenteditable`，这些路径未测；Esc 关闭与关闭后焦点还原已实测（回到「一键生成本周周报」）。
- **图例悬停降透明未单独记数**。点击隔离实测（实际线 opacity 0.3 / 计划线 1），悬停那一路只有代码与截图，没有前后数字。
- **无打印样式、无深浅切换、无 i18n**。页面文案全部硬编码中文。
- **自验是一次性探测脚本，没有进仓库**。受「只许写三个文件」限制，探测代码留在 `/Users/mac/.hermes/cache/scratch/weekdeck/`，仓库里无法一键复跑。
- **JS 依赖**：页面内容由内联脚本渲染。禁用 JS 时只剩静态骨架与页脚，不会降级成可读的静态页。
