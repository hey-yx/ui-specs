# CartLane · 做页过程中发现的问题

只记真踩到的坑：现象、定位到哪一层、怎么改、改完怎么复测。数字都在 `evidence.json` 里，这里的数字是复测时的读数。

## 1 组件库加载：裸模块名挂不上，模板也编译不了

**现象**：import map 指向 `https://esm.sh/tdesign-vue-next@1.20.11` 后页面空白，`#app` 里只有占位文字，控制台报模块解析失败。

**定位**：两件事叠在一起。一是 esm.sh 的默认入口把 `vue` 当外部依赖再请求一次，版本对不上；二是我用字符串 `template:` 写模板，需要带编译器的 Vue 完整构建，`vue.runtime.esm-browser` 没有编译器，模板不会被编译。

**处置**：import map 改成 `vue` 指向 `dist/vue.esm-browser.prod.js`（含编译器），`tdesign-vue-next` 指向 `?external=vue&bundle`，让库复用同一个 Vue 实例并把依赖打成一包。

**复测**：页面挂载，26 张卡片、5 个房间、4 条主推都在；`getComputedStyle(document.documentElement).getPropertyValue('--td-brand-color')` 读到 `#0052d9`。

## 2 页面加载后主线程卡死

**现象**：组件库挂上之后页面白屏，`js()` 读取超时，标签页 CPU 占满。

**定位**：用一个只有一句插值的最小模板替换整段 `template`，页面正常；再按「导航 / 首屏 / 主推 / 目录 / 详情 / 购物车 / 结算 / 页脚 / 搜索面板」逐段加回去，定位到目录区。根因是模板里嵌了一层字符串插值：`{{ loading ? '正在筛选' : ('{{ resultCount }} 件符合条件') }}`，Vue 编译后把里层的 `{{ }}` 当成了又一次求值。

**处置**：内层插值改成字符串拼接 `resultCount + ' 件符合条件'`。

**复测**：整页恢复，`document.querySelectorAll('.card').length` 为 26。

## 3 禁用按钮被变体样式盖掉

**现象**：售罄商品的「已售罄」按钮看着像可点的次按钮，鼠标移上去还有 hover 反应。

**定位**：TDesign 的 `.t-button--variant-base.t-button--theme-primary.is-disabled` 优先级高于我写的 `.t-button.is-disabled`，底色被覆盖。

**处置**：把禁用态选择器提到同等特异性再覆盖一层，同时保留 `disabled` 属性与 `aria-disabled`。

**复测**：禁用按钮底色为 `#f3f3f3`、文字 `#5e5e5e`，对比度 5.84:1；点它不会加购，Tab 也跳不过去。

## 4 卡片按钮在 1280 下只有 24px 高

**现象**：截图里卡片底部的按钮比正文还矮，和旁边的价格标签挤在一起。

**定位**：卡片按钮原本写了 `size="small"`，TDesign 小号按钮 24px 高，低于 WCAG 2.2 的 24px 下限（正好压线）也低于我自己的控件档位。

**处置**：去掉 `size="small"`，回到默认尺寸 32px；主行动按钮（加入购物车、去结算、提交订单）用 40px。

**复测**：`.card__act .t-button` 量到 184×32，`getBoundingClientRect` 复核过。

## 5 320 宽下主推链接折成两行可点文字

**现象**：320 宽截图里「查看 全棉水洗四件套」换行成两行，可点区域变成一条窄长的双行文字块。

**定位**：链接文案带商品名，商品名长度不可控。

**处置**：可见文案改成固定的「打开详情」，商品名放进 `aria-label`（`打开 全棉水洗四件套 的详情`），并给按钮加 `white-space: nowrap`。

**复测**：320 与 375 下链接都是单行，读屏仍能拿到完整商品名。

## 6 自造的两个灰不是色板 token

**现象**：首版 `--ink: #1a1a1a`、`--ink-2: #666666`，跑取值记录时发现这两个值在 TDesign 色板里查不到行号，只能标派生。

**定位**：凭感觉取了「接近黑」和「中灰」，没有回到色板。色板里对应的档是 Gray14 `#181818` 与 Gray9 `#5e5e5e`。

**处置**：换成色板原文值；顺带把 `#fff` 这种缩写也统一成 `#ffffff`，让每个色值都能对到一行原文。

**复测**：全页文字最低对比度从 5.17:1 升到 5.84:1，色值引用全部落到 `content/color/tdesign.tencent.com--color.md` 的具体行。

## 7 页脚与导航的内联链接只有 18px 高

**现象**：量控件尺寸时发现 `.foot__dense a` 只有 48×18，比 24px 目标尺寸下限还矮。

**定位**：`display: inline` 的行内链接高度由行高决定，18px 行高就是 18px 命中区。

**处置**：改成 `inline-flex` 加 `min-height: 24px`，导航链接与「看全部 26 件」同样处理。

**复测**：页脚链接 48×24、导航链接 42×24、看全部 81×24，全页最小命中高度 24px。

## 8 结算校验失败后焦点没落到第一个错误字段

**现象**：空表单提交后 5 条错误文案都出来了，但焦点还在提交按钮上，键盘用户得自己往回找。

**定位**：`errors` 映射里存的是容器 id（`f-name` 是包住输入框的 div），`div.focus()` 无效。

**处置**：先取容器，再 `querySelector('input, button')` 找真正可聚焦的控件；勾选框也给一个固定 id 并纳入映射。

**复测**：提交后 `document.activeElement` 是第一个字段内部的 `input`；勾选框那条错误落在复选框上。

## 9 测试脚本自己取错了空态

**现象**：验证「无结果空态」时读到的标题是「购物车是空的」，判断为页面 bug，查了半天模板。

**定位**：选择器 `.empty__h` 在页面上有两处（目录空态与购物车空态），`querySelector` 命中的是 DOM 里更靠前的购物车空态。

**处置**：读数一律加作用域，`.catalogue .empty` 与 `.cart .empty` 分开取。

**复测**：目录空态读到「没有匹配的商品」加「清空全部筛选」，购物车空态读到「购物车是空的」加「回目录挑一件」，两者不再互相污染。

## 10 视口模拟下 CDP 点击全部落空

**现象**：开了 `Emulation.setDeviceMetricsOverride(mobile=True)` 之后，坐标算得对（`elementFromPoint` 就是目标元素），但点击没有任何反应，排序下拉不展开、规格不切换。

**定位**：模拟视口下的输入坐标与页面 CSS 坐标不是同一套，鼠标事件打在了偏移位置；另外后台标签页需要先 `Target.activateTarget` 加 `Page.bringToFront`。

**处置**：交互实测一律先清掉视口模拟，在自然窗口里点；尺寸与对比度测量才开模拟，两件事分开做。

**复测**：清掉模拟后，排序、规格、数量、加购、移除、运费、校验、下单八组交互全部一次点中，读数记在 `evidence.json` 的 `interactions` 里。

## 11 断点两侧都要量

**现象**：只量 768 与 992 两个整点，看不出列数切换是不是真的落在断点上。

**处置**：加量 767 与 769、991 与 992 三对边界值，同时读 `gridTemplateColumns` 的列数。

**复测**：767 两列 / 768 三列、991 三列 / 992 四列，八档的 `scrollWidth` 与 `clientWidth` 全部相等，横向溢出元素 0 个。
