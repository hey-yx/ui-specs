## 键盘与焦点

Tab 顺序：跳到主内容 → 导航三项 → 搜索 → 状态 → 排序 → 首个行内按钮。焦点环 2px 实线 #0969da，`outline-offset:2px`。批量条在未选中时 `display:none`，不进入 Tab 顺序。

## 状态

四态都在页面上真造出来：空态（文案 + 创建按钮）、加载（三条骨架 + 750ms 播报说明）、错误（左侧红线 + code=upstream_timeout + 重试）、成功（绿字 + 改动前后值）。状态变化用 `role="status" aria-live="polite"` 播报，实测改限额后文本为「prod-worker 的限额已改为 60 万次」。

## 外部请求

`img` 0 个，`src` 或 `href` 指向 http 的资源 0 个；字体用系统栈，无 CDN。

## 交互态与超长内容

- 悬停：按钮用 `filter:brightness(.94)` 压暗，不新取色值；行内按钮悬停时边框换成正文色。
- 按下：再压到 `.86`；禁用：底 `#f6f8fa`、字 `#59636e`、边框 `#d1d9e0`，都是 Primer token。
- 超长：密钥名 `prod-web-apac-cluster-a1` 装在 150px 的格子内，实测 clientWidth 150、scrollWidth 179，出现省略号，`title` 可看全名。
- 未逐个量悬停与按下态的对比度：这两态只改明度、不改色相，文字色仍是 #1f2328，按同一底色算仍在 15.8；按钮按下时是白字压深蓝，未单独量。

## 未测

- 暗色模式未做。
- 批量停用只出按钮，未接确认弹窗。

## 去 logo 与主色复判

去掉品牌名与蓝色后，页面仍是 API 网关控制台：`sk-` 前缀、限额按万次、430 类错误码 `429` 与 `retry_after`、同步超时 `upstream_timeout` 都指向同一类产品，不退回通用后台。
