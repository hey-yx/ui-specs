## 3. 新缺口（指南没有、被迫派生）

1. **预算预警阈值**：什么时候提醒、什么时候算超支，库里没有任何原文（GOV.UK 有 warning text 的**文案**规则，没有**阈值**）。本稿自定 80% 预警 / 100% 超支，两档换底换图标换 `role`。
   **建议回填**：这是所有「额度类」产品的共性维度（预算、配额、存储用量、API 额度），值得在库里加一条「额度阈值与告警档位」。回填前只能派生。

2. **剩余额度的日均折算**（剩 ÷ 剩余天数 = 每天还能花多少）：纯业务算法，不是设计规范。
   **不建议回填**：换个业务就完全变形（剩 23 天和剩 3 天的口气不一样）。

3. **嵌入式数据条（inline data bar）的几何**：Carbon 讲的是图表本体（轴、图例、绘图区），没有「表格行里嵌一条 8px 数据条」这种形态的档位——条高、条与文字的间距、条长归一基准（当期最大值 vs 全局最大值）都得自己定。派生：本稿全用当期最大值归一，并保证轴的起点是 0（`content/dataviz/carbondesignsystem.com--data-visualization-axes-and-labels.md:33`）。
   **建议回填**：列表内联条在后台与工具类产品里极常见，值得补一条「内联条」档（高度、圆角、空轨道色、归一规则）。

4. **金额排版的三处细节**：`guide.md:52` 只给了「两位小数、千分位、负号在币种前、tabular-nums」。没答：正数要不要带 `+`；表格里金额是否省略「元」；超大金额怎么缩写。本稿的选择是——列表省略单位（表头/合计才写「元」）、正数不带符号、不做缩写。
   **建议回填**：把这三条补进金额排版条目，否则每个案例都会各写一套。

5. **抽屉在桌面端的落位**：库内 modal/dialog 只有模式，没有尺寸与桌面落位规则（移动底部、桌面居中 480 还是右侧 400）。本稿统一底部弹出、最大宽 480。
   **建议回填**：低优先级，但会直接影响「移动优先」项目的桌面观感。

6. **空态的措辞标准**：GOV.UK/Carbon 讲了空态的结构（替换原内容、给一个主行动），没给中文措辞样例。本稿写「这里还没有记录。」+「看全部」。
   **不建议单独回填**：属于文案规范（`content/principles/ant.design--copywriting-cn.md` 范畴）已覆盖的部分。

## 4. 已知局限

1. **无持久化**：单文件演示，数据在内存里，刷新即回初始值。页脚已如实写明，不假装是云服务（也符合需求里「不做云同步」的边界）。
2. **数据是示例数据**：3,286.50 的月度分布、6 条流水都是构造成本合理的样例，不是真实账单。带 ⚠️ 的是：这些数字**不是**实测得出的用户数据，页面也不宣称是。
3. **只测了 Chromium**：四档、行高、对比度、交互全在 Chrome 跑；Safari / Firefox 未测。已知风险点是 `:has()`（分类选中态）与 `inert`（抽屉关闭）——两者 Chrome/Safari 16+/Firefox 112+ 均支持，但未在真机验证。
4. **没跑读屏**：做了结构（label 关联、`aria-describedby`、`fieldset/legend`）、属性（`aria-invalid`、`aria-pressed`、`role=status/alert`、`aria-valuenow`）与焦点行为（错误汇总接管焦点、抽屉 Tab 圈定、Esc 回位）核对，但**没有用 VoiceOver/NVDA 真听一遍**，所以「能读对」只是结构性判断。
5. **没测 200%/400% 缩放**：WCAG 1.4.4 重排只在四档宽度上验了横向溢出，没在放大字号与浏览器缩放下复测。
6. **图表无数据表替代**：Carbon 建议给表格视图（`content/dataviz/carbondesignsystem.com--data-visualization-chart-anatomy.md:68` 提到数据表是唯一可达路径）。本稿的行内条把分类名与金额都写成真实文本，读屏能读到值，但没有独立 `<table>` 视图；极小值（占比 < 1%）也不会被条长表达。
7. **只有亮色**：基准规范有暗色篇（`content/color/tdesign.tencent.com--dark.md`），本稿未启用，也没做主题切换。
8. **一份基准规范**：整站数值只用 TDesign，未做跨体系对照；如果换基准规范（Carbon/Polaris），字号与间距会整体变形，不是换几个 token 就能搬的。
9. **未做真实碰撞检索**：产品名 TallyLane 由需求给定，本稿没有重新跑命名核验。
