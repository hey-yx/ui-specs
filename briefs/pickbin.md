# 建站需求 · PickBin（pickbin）

- 语言：中文
- 产品：临时文件快递柜 Web 工具，把文件上传拿到取件码，对方凭码取走。
- 受众：要临时把文件传给同事或客户、不想注册也不想装 App 的人。
- 核心任务：三步走完一次传文件，投柜 → 取码 → 取件。
- 语气：事务性但不冷：像寄存柜上的提示语，只说下一步和注意事项。
- 差异化约束：冷青灰的柜面质感；三段流程各占一段，靠分段与留白区分，不靠装饰。
- 页面必备内容：
  - 投柜：选择文件、填写到期时间、生成取件码
  - 取件：输入取件码
  - 三段各自的进度与成功态
  - 使用限制说明（单文件大小、保存时长、下载次数）
- 边界：上传下载是前端模拟，不做真实存储、不做账号体系。
- 名字：PickBin
- 分类：文件工具
