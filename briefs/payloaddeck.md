# 建站需求 · PayloadDeck（payloaddeck）

- 语言：英文
- 产品：日志解析 API 的开发者文档站。工程师读 Quickstart 就能发出第一个能跑的请求，再查字段和错误码。
- 受众：要在半小时内接入日志解析的后端 / 平台工程师。
- 核心任务：照着 Quickstart 跑通一次请求，然后查表确认字段与错误码。
- 语气：技术说明口吻：第二人称、祈使句、不寒暄。
- 差异化约束：近黑底配青绿（终端感）；左目录常驻、右正文的双栏文档骨架。
- 页面必备内容：
  - Quickstart：可复制的 curl 请求与响应示例
  - 请求字段表
  - 错误码表
  - 目录（左侧章节、右侧页内）
  - 版本与构建信息
- 边界：不做真 API 调用，示例响应是静态的。
- 名字：PayloadDeck
- 分类：开发者文档

> 本文件由 `briefs/sites.json` 生成，改需求改 JSON；站点页面与 `/ai/case-briefs.json` 读同一份。
