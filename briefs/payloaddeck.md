日志解析 API 的开发者文档站，给要在半小时内接入日志解析的后端与平台工程师用。

## 产品与用户

- 产品：PayloadDeck，把一行日志解析成结构化 JSON 的 HTTP API，单次最多 500 行。
- 用户：后端与平台工程师，通常带着一个具体日志格式来查字段与错误码，目标是半小时内发出第一条请求。

## 主任务

拿到 API key，发出第一条请求，看懂返回的字段，处理常见错误，之后接进自己的日志管道。

## 关键内容

- 快速开始：获取 key、curl 示例、第一份响应。
- 端点：POST /v1/parse，请求体字段与限制。
- 字段：timestamp、level、service、message、trace_id 等解析出的结构。
- 限制：单次 500 行、单请求 1 MB、免费 10,000 行/月，超出按量计费（演示口径）。
- 错误码：400 格式错误、401 未授权、413 超限、429 限流、500 解析失败，各给处理建议。
- 延迟：p95 120 ms（演示口径）。
- SDK：npm @payloaddeck/node 0.4.2，附最小示例。
- 试解析：页面内可以直接贴一行日志看结果。

## 可用的内容材料

三行不同格式的日志样本、请求与响应示例、错误码表、SDK 示例、限流说明。

## 假设

- 不接真实解析服务，试解析用演示结果。
- 额度、延迟、版本号为演示口径。
