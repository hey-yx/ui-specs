# 建站需求 · SwimBoard（swimboard）

- 语言：中文
- 产品：团队任务看板的工作台，打开就是本周冲刺的看板，不是营销页。
- 受众：产品设计组这类小团队，成员每天在这里认领和推进任务。
- 核心任务：看清本周哪些任务在哪个阶段、谁负责、什么时候到期，并新建或移动任务。
- 语气：工具腔、短句、名词开头；不用营销动词，不寒暄。
- 差异化约束：中性灰面配一档饱和蓝绿强调；侧栏、看板、详情同屏排开。
- 页面必备内容：
  - 侧栏：项目列表、我负责的、收件箱、常用筛选
  - 本周冲刺看板：待办 / 进行中 / 评审 / 完成 四列
  - 任务卡：标题、标签、负责人、截止日
  - 本周进度统计
  - 新建任务弹窗（标题、所属列、标签、负责人、截止日）
  - 搜索（⌘K）
- 边界：不做服务端，不做通知推送、不做账号。
- 名字：SwimBoard
- 分类：项目看板
