大模型 API 价格比价站，给要挑中转服务商的开发者和独立开发者用：同一档能力横向比价，每条价格都能点开核对来源和更新时间。

## 产品与用户

- 产品：PriceLens，收录 18 家服务商、42 个模型的价格与来源。
- 用户：要给项目选 API 的开发者，关心同一个模型在不同服务商的实际单价、计费口径和稳定性。

## 主任务

按模型或服务商找到同一档能力的报价，比较输入与输出单价，点开来源核对，判断哪家值得试。

## 关键内容

- 服务商：名称、类型（官方直连、中转、共享）、覆盖模型、支付方式。
- 价格：输入与输出单价，统一换算成元/百万 token，标注原始币种与汇率（演示口径 7.2）。
- 来源：每条价格带原文链接、抓取时间、最近核对时间。
- 模型档位：旗舰、主力、轻量三档，同档才横向比。
- 计费口径：按 token 还是按次、是否有最低消费、缓存是否折价。
- 更新：每天 09:00 抓取，价格变动标出前后值。
- 免责：价格以服务商页面为准，本站只做汇总。

## 可用的内容材料

18 家服务商的价格表、来源链接、变动记录、口径说明、汇率。

## 假设

- 价格为演示样本，不代表真实报价。
- 服务商与模型覆盖为演示数据。
