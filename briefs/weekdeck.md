# 建站需求 · WeekDeck（weekdeck）

- 语言：中文（产品名英文）
- 产品：团队周报看板，把一周的进展、燃尽情况和成员周报收在一页。
- 受众：团队负责人与成员，每周五下午看本周进展。
- 核心任务：看本周 KPI 与燃尽情况、逐个看成员周报、一键生成本周周报摘要。
- 语气：直陈事实：先数字，后一句解释；不写「闭环」「赋能」。
- 差异化约束：暖灰纸感配砖红强调；整页像一份可打印的周报，纵向排。
- 页面必备内容：
  - 周期切换（本周 / 上周）
  - 本周完成数主数字与说明
  - 燃尽图（带图例与坐标轴）
  - 成员周报列表，可展开
  - 一键生成周报：进度态 → 摘要文本 → 成功提示
- 边界：不做真后端。
- 名字：WeekDeck
- 分类：周报工具
